# ChefClaude_LangChain_agent

Chef Claude is a warm and knowledgeable personal chef assistant built with **LangChain** and **LangGraph**. It helps users decide what to cook based on cuisine preferences and dietary needs, providing clear, encouraging step-by-step recipes by performing live web searches.

## ⚠️ Disclaimer & Warnings

- **No Guardrails:** This system is currently in a developmental state and does not have safety guardrails or input/output filtering. It may respond to prompts outside the culinary domain or generate unexpected content if prompted maliciously.

- **AI Accuracy & Safety:** Recipes are generated by an LLM and retrieved via web search. Always use your best judgment when following instructions. Verify cooking temperatures, ingredient safety (especially regarding allergies), and preparation methods before consuming.

- **API Usage & Costs:** This application makes calls to the OpenAI and Tavily APIs. Ensure you monitor your usage to avoid unexpected charges on your accounts.

- **Experimental Project:** This tool is intended for educational and demonstration purposes. It should not be relied upon as a primary source for food safety or professional culinary advice.

## Features

- **Dish Recommendations:** Suggests the best dishes to cook based on a specific cuisine (e.g., Italian, Japanese) and dietary restrictions (e.g., Vegan, Gluten-free).
- **Step-by-Step Recipes:** Provides detailed instructions and ingredient lists for specific dishes.
- **Live Web Search:** Uses the Tavily API to ensure recommendations and recipes are up-to-date and comprehensive.
- **Intelligent Agent:** Powered by GPT-4o-mini, the agent can handle multi-tool requests, such as recommending a dish and then providing the recipe in a single interaction.
- **Warm Persona:** Features an enthusiastic and supportive personality designed to make cooking approachable and fun.

## Tech Stack

- **Framework:** LangChain & LangGraph
- **LLM:** OpenAI GPT-4o-mini
- **Search Engine:** Tavily Search
- **Package Manager:** uv
- **Environment:** python-dotenv

## Installation

Follow these steps to set up the project locally using **uv**:

### 1. Clone the Project

Navigate to your project directory:

```bash
# Assuming you are already in the project folder
cd ChefClaude_LangChain_agent
```

### 2. Create and Activate a Virtual Environment

Using **uv**, you can create a virtual environment and install the dependencies listed in `requirements.txt`:

```bash
# Create the virtual environment
uv venv

# Activate the environment
# On macOS/Linux:
source .venv/bin/activate
# On Windows:
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
uv pip install -r requirements.txt
```

### 4. Set Up Environment Variables

Create a `.env` file in the root directory to store your API keys. The project requires an OpenAI key for the brain and a Tavily key for web searching:

```bash
# .env file
OPENAI_API_KEY=your_openai_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here

# Optional: LangSmith Tracing
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key_here
```

## Usage

To start chatting with Chef Claude, run the `main.py` script:

```bash
python main.py
```

Once the "kitchen" is open, you can ask questions like:

- "What are some Japanese vegan dishes I can cook?"
- "How do I make a Margherita Pizza step by step?"
- "Can you recommend an Italian dish and give me the recipe for it?"

Type `exit`, `quit`, or `Ctrl + C` to leave the application.

## Project Structure

- **main.py:** The entry point containing the agent logic and Chef Claude's persona.
- **tools.py:** Contains the custom LangChain tools for dish recommendations and recipe fetching via Tavily.
- **requirements.txt:** List of all Python libraries required for the project.
- **.env:** (User-created) Stores sensitive API credentials.
